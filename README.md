# Federated Learning for Malaria Surveillance in Sub-Saharan Africa

> Undergraduate thesis — Bachelor in Transformational Leadership and Social Impact (BITLASI), Esade  
> A multimodal federated learning framework integrating climate, genomic, and microscopy data across simulated clinic nodes, with Shapley-based IP token governance.

---

## Overview

This project implements a privacy-preserving federated learning (FL) pipeline for malaria risk surveillance across 10 simulated clinic nodes in Sub-Saharan Africa. Rather than centralising sensitive patient data, each node trains locally and contributes model updates to a global aggregator — enabling collaborative learning without data sharing.

**Three data modalities are fused at each node:**

- 🌦️ **ERA5 climate data** — temperature, precipitation, humidity (via Copernicus CDS)
- 🧬 **MalariaGEN Pf8 genomic markers** — drug resistance and population structure signals
- 🔬 **NIH microscopy cell images** — parasite detection from blood smear images

A **Shapley value-based IP token governance module** rewards nodes proportionally to their contribution to global model performance — addressing the incentive problem in federated health systems.

**Key result:** Global AUC ~0.83 (mean over 20 FL rounds), with a notable finding at the Lusaka node (high Shapley value despite AUC ~0.5, attributed to a unique drug-resistance genomic profile).

## Data Sources

Raw data is **not included in this repository** due to size and licensing. Download from the following sources and place in the directories indicated:

| Dataset | Source | Place in |
|---|---|---|
| ERA5 climate reanalysis | [Copernicus Climate Data Store](https://cds.climate.copernicus.eu/) | `ERA/` |
| MalariaGEN Pf8 genomic data | [MalariaGEN](https://www.malariagen.net/resource/34/) | `pf8/` |

## Setup & Installation

**Requirements:** Python 3.9+

```bash
# Clone the repo
git clone https://github.com/your-username/thesis-malaria-fl.git
cd thesis-malaria-fl

# Create a virtual environment
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

> ⚠️ A `requirements.txt` will be added. Core dependencies include: `torch`, `numpy`, `pandas`, `cdsapi`, `xarray`, `scikit-learn`, `matplotlib`.

## Running the Pipeline

```bash
# Full end-to-end run
python real_data_pipeline.py

# Run FL training loop only (assumes data already preprocessed)
python malaria_fl/main.py
```

ERA5 ingestion runs separately before the main pipeline:

```bash
python era5_ingestion_v2.py
```

## Key Design Decisions

- **Label derivation** uses real ERA5 precipitation values — avoiding the leaky `img_weekly_pos_rate` feature that caused the initial label-decorrelation bug at the Lusaka node
- **FedAvg aggregation** with a custom contribution-weighted variant tested in later rounds
- **Shapley values** are computed per round and accumulated in `ip_token_ledge.csv` — forming the basis of the governance module
- **The Lusaka paradox** — high token reward despite low local AUC — is discussed in the thesis Discussion as a case study in why contribution ≠ accuracy in federated health systems
